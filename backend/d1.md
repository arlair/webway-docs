# Cloudflare D1

Use D1 through the target project's binding and adapter/repository boundary.

- Read the target project's Wrangler, runtime and data-lifecycle guidance
  before changing D1 access.
- Do not replace a D1 adapter with PostgreSQL or `withSql` by assumption.
- Keep local, stage and production database authority explicit; a local
  SQLite snapshot is not automatically a published D1 database.
- For schema, publication or lifecycle changes, read the relevant local ADRs
  before editing code.
