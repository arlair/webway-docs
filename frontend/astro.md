# Astro

Use for Astro pages, layouts, content collections, integrations and islands.

- Keep page/content generation and interactive island behavior at their
  intended boundaries; do not turn a static page into a client application
  without a reason.
- Svelte components rendered as islands also follow the
  [Svelte guidance](./svelte.md).

Read the [Astro site architecture template](../architecture/templates/astro-site.md)
and [`@eldarlabs/astro` package docs](../../../packages/astro/README.md) when
shared Astro structures are involved.
