# Styling

For projects using Tailwind CSS 4 and DaisyUI 5:

- Prefer DaisyUI semantic classes and theme tokens for ordinary themed UI, for
  example `btn-primary`, `bg-base-100`, `text-base-content` and
  `border-base-300`.
- Do not add raw Tailwind palette colors to ordinary themed UI.
- Games, prototypes and deliberately brand-specific surfaces may use local
  exceptions; follow the target project's guidance.
